# Arunika brand files

| File | What |
|---|---|
| `arunika-logo.svg`, `arunika-logo-512.png` | The Arunika logo: a sunrise-orange tile with the island hanging from its top edge, playing music (album cover and equalizer, as on the real island), and a white rising sun below it |

Both are generated: `python3 tools/make_brand.py` redraws them together with `crates/poni/res/arunika.ico` and everything in `installer/art/`.

These files are Arunika's brand and are not covered by the MIT license that covers the code. The Outfit font (in `crates/poni/res/fonts/`) is under the SIL Open Font License.
